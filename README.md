# Saipatri Homestay Website

## Overview

This project is a custom-designed website for Saipatri Homestay, located in Kalimpong, West Bengal. The goal was to create a visually appealing and easy-to-use platform to showcase the property, highlight experiences, and enable direct booking inquiries.

## Development

* Built with assistance from AI tools (GitHub Copilot) to streamline development
* All design decisions, structure, and final implementation were customized and refined manually

## Features

* Fully responsive design (mobile, tablet, desktop)
* Room listings and image gallery
* Booking/contact form integration
* Smooth scrolling navigation
* Clean and minimal UI for ease of use

## Tech Stack

* HTML, CSS, JavaScript
* Modern layout techniques (Flexbox/Grid)
* Deployed via Vercel

## Deployment

The website is deployed and maintained by the developer. Updates may be made over time to improve performance and usability.
